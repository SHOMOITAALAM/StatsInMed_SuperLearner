Code for "Should a propensity score model be super? The utility of ensemble procedures for causal adjustment"
This repository contains the R code used in the analyses presented in the paper:

Alam, Shomoita, Erica E. M. Moodie, and David A. Stephens (2019).
Should a propensity score model be super? The utility of ensemble procedures for causal adjustment. Statistics in Medicine, 38(9), 1690–1702.
https://doi.org/10.1002/sim.8051
